Core Concepts for Modern Web Design

Three Core Principles

Learn the basic techniques that make websites flexible and responsive.

Fluid Layouts

Fluid layouts use relative units such as percentages to allow elements to resize according to the available screen width.

width: 100%;
max-width: 1200px;

Flexible Media

Flexible media allows images and other content to resize within their containers without overflowing.

img {
  width: 100%;
  height: auto;
}

Breakpoints

Breakpoints use media queries to change the layout when the screen reaches a particular width.

@media (max-width: 600px) {
  .container {
    display: block;
  }
}
