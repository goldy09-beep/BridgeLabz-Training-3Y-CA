Effects Used

  • :hover changes the style when the mouse is over an element.
  • :active applies an effect while the button is being clicked.
  • :focus highlights the button when it receives focus.
  • transition makes changes smooth instead of sudden.
  • transform is used for scale, rotate and move effects.
  • box-shadow gives the elements a subtle depth effect.
  • Flexbox distributes the examples evenly across the page.
