Quick Reference for Responsive Web Design

CSS Concepts

A quick reference to important CSS techniques used for creating responsive websites.

Filters

CSS filters can change the visual appearance of an element such as an image.

filter: grayscale(100%);

Media Queries

Media queries apply different CSS rules depending on the screen size or device.

@media (max-width: 700px)

Responsive Design

Responsive design makes a website adapt smoothly to different screen sizes.

width: 100%;

Typography

Responsive typography allows text to scale according to the available screen size.

font-size: clamp(1rem, 2vw, 1.5rem);

Flexbox

Flexbox provides an easy way to align and distribute elements inside a container.

display: flex;

CSS Grid

CSS Grid creates structured layouts using rows and columns.

display: grid;
