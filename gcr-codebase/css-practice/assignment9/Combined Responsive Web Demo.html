Responsive Design

Responsive web design allows a website to adapt to different screen sizes and devices.

CSS Flexbox, Grid, media queries and relative units can be combined to create flexible layouts.

@media (max-width: 700px)

At smaller screen sizes, the layout changes from multiple columns into a single column.

CSS Cheat Sheet

Flexbox Used for one-dimensional layouts.
Grid Used for rows and columns.
Media Queries Adapt styles according to screen size.
Clamp() Creates flexible and responsive text sizes.
Transitions Creates smooth hover effects.
