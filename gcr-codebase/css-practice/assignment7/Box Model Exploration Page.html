CSS Box Model Exploration

Every HTML element is made up of content, padding, border and margin.

Content

This is the actual content of the element.

Box Model Parts

Content: The actual text or information inside an element.

Padding: Space between the content and the border.

Border: A line surrounding the padding and content.

Margin: Space outside the border that separates elements.

Outline: An extra line outside the element, shown as a dashed line.
