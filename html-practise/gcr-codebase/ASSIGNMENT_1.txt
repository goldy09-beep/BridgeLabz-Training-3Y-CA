ANS-1 : Frontend development is everything a user sees and interacts with directly in the browser — layout, colors, buttons, forms, animations. It's built with HTML, CSS, and JavaScript (often frameworks like React or Vue). Example: the menu, cart page, and checkout screen you interact with on Amazon.

Backend development is the server-side logic that frontend never shows you — processing orders, checking inventory, talking to databases, handling authentication. Built with languages like Node.js, Python (Django/Flask), Java (Spring), or PHP. Example: when you click "Buy Now" on Amazon, the backend verifies stock, charges your card, and creates an order record.

Full-stack development means working on both sides — building the interface and the server logic that powers it. A full-stack developer might build a food-delivery app's ordering screen (frontend) and the logic that assigns it to a nearby restaurant and driver (backend).

ANS-3 : DNS lookup — you type a URL, the browser asks a DNS server to translate the domain name into an IP address.
Connection — the browser opens a TCP connection to that IP (usually secured with TLS for HTTPS).
HTTP request — the browser sends a GET request for the page.
Server response — the server returns an HTML document
Parsing and rendering — the browser parses the HTML into a DOM tree, fetches linked CSS and JS, builds the render tree, and paints pixels to the screen.
JavaScript execution — scripts run, which may fetch more data (via APIs) and update the page dynamically.

Rendering Engine
A rendering engine converts HTML, CSS, and JavaScript into the visual webpage shown in the browser.
Differences:
>Blink: Fast and widely used (Chrome, Edge, Opera).
>Gecko: Mozilla's independent engine, focused on web standards.
>WebKit: Used by Safari, optimized for Apple devices.
