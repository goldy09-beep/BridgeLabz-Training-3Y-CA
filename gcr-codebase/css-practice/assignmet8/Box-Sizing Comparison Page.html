Box-Sizing Comparison

Comparing the default content-box with border-box.

Content-Box

This is the default box-sizing value. The width applies only to the content. Padding and border are added outside the given width.

Border-Box

With border-box, the given width includes the content, padding, and border. This makes the total size easier to control.

How Box-Sizing Works

content-box: The specified width is only the width of the content. Padding and border are added to the total size.

border-box: The specified width includes the content, padding, and border, so the total size remains equal to the specified width.

Both boxes have the same width, padding, and border, but their total sizes are different because of the box-sizing property.
